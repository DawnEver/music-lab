## 2026-09-04 — 口琴调音变体与超吹模型纠错

### What changed
- **`harmonicaVariants`(后被重命名为 `variants`/`reeds`)**:同一件乐器可以有多套簧片布局。`标准 Richter` 与 `Paddy Richter` 并列,**调(key)仍留在 presets**,不做 12×2 的笛卡尔积塞进一个下拉。UI 只在 `instrument.variants` 存在时才多出一个"调音法"选择器。
- **Paddy Richter 数据**:3 孔吹音升全音(C 琴 G→A),其余照旧;**3 孔吸音压音深度随之从 3 半音降到 1** — 压音只能向下逼近同孔另一簧片,吹簧升高了,压音空间就没了。这是数据的物理后果,不是另一张表。
- **超吹/超吸模型纠错(原模型是错的)**:超吹 = **吸簧 + 1 半音**,超吸 = **吹簧 + 1 半音**。原来一律写成"本簧 +1",于是 C 琴 1 孔超吹算出 C♯4(实际 E♭4)、8 孔超吸算出 E♭6(实际 F6)。同一条也解释了**为什么超吹只存在于 1–6 孔、超吸只存在于 7–10 孔**:需要对侧簧片更高。
- 检测频带上限随之提到 midi 103(F♯ 琴 10 孔超吸)。

### Validation
per-hole 测试逐条锁定(整行超吹/超吸 + Paddy 的 3 孔特例);`npm test` 全绿。

### Reusable insight
- **乐器"变体"和"调"是两个正交维度**,别用一个下拉承载两个维度的乘积。
- 物理模型写错时,单测只会锁住错误 — 纠错的正确做法是先写出**成因**(超吹发的是对侧簧片),再让数据从成因推出来。

## 2026-09-04 — 乐器覆盖从 8 件补到 19 件

### What changed
- 拉弦补齐:中提琴、大提琴、低音提琴(四度定弦 + 五弦 B0 + 低音 C 延伸)、中胡、高胡(含广东音乐 a-e1)。
- 弹拨补齐:曼陀林、班卓(开放 G / Double C / 开放 D,**五弦回旋弦按物理顺序存,不按音高排序**)、琵琶、阮(中/大/小)、柳琴;吉他加七弦、尤克里里加上低音 DGBE。
- 其他:卡林巴 17 音 C 调,**按琴体位置存**(中间 C4 最长,向两侧交替升高),不是音阶顺序。
- `InstrumentCategory` 从 `strings|winds` 改为 `plucked|bowed|winds|other`,选择器用 category 生成小标题分组(19 件平铺已不可用)。
- 顺手收紧古琴/中胡/琵琶过宽的检测频带(古琴原来下探 26 Hz,最低弦 62 Hz)。

### Reusable insight
- 手工维护的 `range` 会漂:同一次会话里就写错两次,全靠测试兜住 → 最终改成 `deriveRange()` 从乐器能发出的所有音高推导。**能推导的字段不要存**。
- 回旋弦(班卓 5 弦、尤克里里高 G)和卡林巴的排列都说明:**notes 数组的顺序是"物理顺序"而非音高顺序**,这条不变式必须写进注释和测试,否则后来者一定会 sort。
